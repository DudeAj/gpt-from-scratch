Creating folders and configuration files is effectively O(1) with respect to model size.

The computationally expensive work begins when we process tensors:

Embedding lookup: approximately O(B × T × d)
Feed-forward network: approximately O(B × T × d²) (depending on hidden dimension)
Self-attention: approximately O(B × T² × d)

where:

B = batch size
T = sequence length (context length)
d = embedding dimension
